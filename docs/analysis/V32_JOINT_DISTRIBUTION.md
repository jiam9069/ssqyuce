# V32 组合级联合分布建模：二阶结构、一阶偏置、以及"最强候选"的失败

**日期**：2026-10-24
**触发**：用户「先放下经济价值，按照理论上仍可行的方向走下一步」
**前置**：V30（17 项维度检验，0 项通过）、V31（13 架构嵌套置换，真实信号 −0.74%）
**结论一句话**：**在 V30/V31 之外，首次检验了「组合级联合分布」这条从没走过的路。发现了全场唯一一个通过置换检验的统计量（一阶边际 χ²=45.07, 置换 p=0.0094），但它①未过 Bonferroni、②as-of 可跟随性检验失败（准确率 0.4948 < 常数基线 0.8182）、③即便成立也只能把命中率从 1.0909 提到 1.1066。**

## 0. 为什么"放下经济价值"是对的，也是危险的

用户说得对：V30/V31 都用"经济价值为零"来收尾，这确实会让人误以为"如果有价值就值得做"。所以本轮**完全不谈钱**，只问一个问题：

> **是否存在任何一个统计量，在严格的置换检验下显著，且可被前向利用？**

只问这个。不谈 EV，不谈回收率，不谈"值多少分钱"。

但危险在于：一旦不谈经济价值，"显著"就会被当成"找到了"。所以本轮额外加了两道 V30/V31 没有的关卡：

1. **as-of 可跟随性**：这个偏置能不能用**当期之前**的数据估出来，并真的提高下期命中率？
2. **常数基线对照**：任何策略必须击败"总是预测不出现"（0.8182）才算有信息。

---

## 1. 先说被排除的方向

### 1.1 直接对 C(33,6) = 1,107,568 种组合建模

```
组合空间: 1,107,568
现有期数: 3,518
稀疏度:   1/1,107,568 = 9.03e-07

让每个组合平均被观察到 1 次 → 需 1,107,568 期 = 7,384 年
平均观察 10 次            → 需 11,075,680 期 = 73,838 年
```

**不可行，且不是"数据再攒几年就够"的问题。** 直接排除，不浪费算力。

### 1.2 序列级生成模型

"把 3518 期当一条序列训练"——这需要序列有可学习的转移结构。V30 已测：

- 相邻期重号数 1.0830 vs 理论 1.0909（p=0.7010）
- 和值自相关 lag1-5：−0.002 / −0.021 / −0.018 / −0.036 / −0.027（全在 2se 内）
- 蓝球相邻重复率 z=+1.62（唯一候选）

**没有记忆，生成模型学不到转移。** 这条与 V31 的时序网络重复，不重复做。

### 1.3 本轮真正的新方向：组合级**联合**分布

V30/V31 的共同缺陷是：**33 个号各自独立建模**。但实际约束是"每期恰好 6 个号"，号与号之间存在**负相关**（一个号出现会压低其他号的概率）。

任何独立建模都在违背这个约束。正确做法是建**联合分布**。

---

## 2. 二阶共现（Ising 风格 pairwise）—— 第一个看似成功的结果

### 2.1 做法

统计所有 528 个号对（C(33,2)）的共现次数，与超几何期望比较：

```
每对号同时出现概率: (6/33) × (5/32) = 0.02841
期望次数: 3518 × 0.02841 = 99.94
观测:     均值 99.94   sd 10.87   min 71（16-33）  max 136（6-14）
```

### 2.2 第一遍计算：χ² = 762.7

```
df = 528，期望 528 ± 65
观测 762.7 → 超出 3.6 个标准误
最热对 6-14：136 次（期望 99.9），z = +3.99
```

**这是本轮第一个"看起来非常显著"的结果。**

### 2.3 但它是假的——诊断过程（重要）

我做了三层拆分：

**① 时间置换**（打乱期序，保留每期号码集合）：

```
chi2 置换均值 762.7，sd 0.0
p = 0.998
```

**sd=0.0 说明这个统计量完全不随时间顺序变化**——所以它不是"时间结构"，而是**号码集合的固有属性**。

**② 独立重抽**（每期重新抽 6 个号，模拟真随机）：

```
chi2 置换均值 625.5，sd 50.4
p = 0.0060    ← 看起来显著
max_z 置换均值 +3.49，sd 0.43
p = 0.1477    ← 不显著
```

**两个判据矛盾。** 必须查清。

**③ 条件化：扣除一阶（单号频次）影响**

关键洞察：如果某个号出现特别多，它与其他所有号的 pair 都偏高 → χ² 膨胀。

```
条件 chi2（给定每号出现次数）= 452.6
df = 528，期望 528 ± 65
```

**452.6 低于期望 528。** 也就是说：

> **二阶结构（号与号的相关性）不但不存在，还比独立假设更"均匀"。**

那 762.7 里的全部超额，都来自**一阶**（单号频次不均匀）。

## 3. 一阶边际：本场唯一通过置换检验的量

### 3.1 事实

```
单号出现次数：最高 14 号 695 次，最低 33 号 581 次
期望：3518 × 6/33 = 639.6
chi2 = 45.07  (df=32)
```

### 3.2 判据的矛盾，以及哪个才对

```
经典卡方临界值（df=32, α=0.05）: 46.19
观测 45.07 → 低于临界，判"不显著"
置换检验 p = 0.0094  → 判"显著"
```

**置换检验才对。** 原因：

```
模拟：每期独立抽 6 号（B=2000）
chi2 均值 26.74，sd 6.78

理论卡方分布：均值 32，sd 8.00
```

**零分布均值是 26.7，不是 32。** 因为每期抽 6 个**不放回**，33 个计数之间有"和为定值"的约束（Σcnt = 21108），导致各项负相关，χ² 统计量的实际零分布被压缩。

用卡方表（假设各项独立）会**高估**临界值，从而漏判。**这是本轮一个真实的方法论收获。**

### 3.3 但仍未通过 Bonferroni

```
33 个号各测一次 → 阈值 p = 0.05/33 = 0.00152（对应 z ≈ 3.17）
14 号 z = +2.42
```

**未通过。** 而且"最高的是 14 号"本身是看过数据才选的——这正是 V31 反复强调的选择偏差。

## 4. 决定性的关卡：as-of 可跟随性

即使偏置真实存在，能利用吗？用一个最直接的策略检验：

```
策略：用最近 500 期估计某号的出现率 p
      若 p > 6/33，预测下期出现；否则预测不出现
      （严格 as-of：只用 t 之前的数据）
```

### 4.1 结果

```
14 号单独：准确率 0.2843  (n=3018)
全部 33 号：准确率 0.4948  (n=9966)
```

### 4.2 对照基线

```
总是预测"不出现"：0.8182   ← 因为每期只有 6/33 = 18% 的号会出现
总是预测"出现"：  0.1818
```

> **跟随偏置的策略（0.4948）比"总是猜不出现"（0.8182）差了 32 个百分点。**

这不是"效果不好"，这是**比什么都不做还差**。

### 4.3 为什么必然如此

因为号码之间是**互斥的**：33 个号里每期只出 6 个。任何"猜更多号出现"的策略都会推高假阳性。而 18% 的基础率意味着"猜不出现"天然有 82% 正确率。

**判据必须用命中率，不能用分类准确率。** 这一点我下一步就补。

## 5. 换成命中率判据：偏置的收益上限

用唯一有意义的口径（top-6 命中数，基线 1.0909）：

| 历史窗口 | 命中（个/期） | 相对基线 |
|---:|---:|---:|
| 200 期 | 1.1229 | +2.94% |
| 500 期 | 1.1074 | +1.51% |
| 1000 期 | 1.1183 | +2.51% |
| 2000 期 | 1.1345 | +4.00% |
| 3500 期 | 1.1146 | +2.18% |

全部 +1.5%~+4%。**但 V30 已经证明：同样的方法在纯随机序列上也 +1.54%**（估计偏差）。

所以这些超额**不能当作偏置的贡献**。

### 5.1 剥离估计偏差后，14 号偏置的真实上限

```
14 号真实出现率: 695/3518 = 0.1976
理论:            6/33     = 0.1818
提升:            +8.66%

若下期真按这个概率：
  选 14 号的单号命中率提升: +8.66%
  6 个号里只有 14 号有偏置 → 整注提升: +8.66%/6 = +1.443%
  即 1.0909 → 1.1066 个/期
```

**上限 +1.443%。** 而这还是假设"偏置永续、且可被精确估计"的理想情况。

## 6. 14 号的逐年表现（稳定性检查）

```
27 个滑动窗口（每窗 250 期）：20 个高于期望（74.1%）

最近 6 年：
  2021: 32/150 = 0.2133
  2022: 30/150 = 0.2000
  2023: 31/151 = 0.2053
  2024: 22/151 = 0.1457   ← 低于期望
  2025: 31/151 = 0.2053
  2026: 26/121 = 0.2149
```

方向大体一致（74% 窗口偏高），但**2024 年跌破期望**，说明它不是"物理偏置"（物理偏置不会某年消失）。

**更可能的解释**：14 号的偏高是 3518 期样本里的随机游走。33 个号中总会有一个"运气好"，而 74% 的窗口偏高并不罕见——**因为窗口是重叠的**（每 125 期滑动一次，相邻窗口共享一半数据），所以"20/27"远不是 27 次独立检验。

## 7. 结论

### 7.1 直接回答用户

> 「按照理论上仍可行的方向走下一步」

**走了。找到的是：二阶联合结构不存在，一阶边际有一个 p=0.0094 的候选，但它不可利用。**

具体：

| 方向 | 状态 | 结论 |
|---|---|---|
| 直接对 110 万组合建模 | 排除 | 需 7,384 年数据 |
| 序列级生成模型 | 排除 | 无转移结构（V30 已证） |
| **二阶共现（Ising）** | **已测** | **条件化后 452.6 < 期望 528，无二阶结构** |
| **一阶边际偏置** | **已测** | **置换 p=0.0094，但未过 Bonferroni (z=2.42 < 3.17)** |
| **偏置可利用性** | **已测** | **as-of 跟随策略 0.4948 << 常数基线 0.8182** |

### 7.2 本轮的真实收获（方法论层面）

有三条，都比"发现信号"更值钱：

**① 卡方表在这里会骗人**

```
零分布实际均值 26.74（不是理论 32）
因为每期抽 6 个不放回 → 33 个计数有"和为定值"约束 → 负相关 → 方差压缩
```

用卡方表（观测 45.07 < 临界 46.19）会判"不显著"，而置换检验给 p=0.0094。**分布假设错了，临界值就错了。**

**② 二阶 χ² 会把一阶偏置放大成假信号**

```
未条件化: χ² = 762.7（看起来极显著，z=+3.99）
条件化后: χ² = 452.6（低于期望 528，毫无结构）
```

一个号多出现 55 次，会让它参与的全部 32 个 pair 都偏高 → χ² 膨胀 300+。**任何"看号对共现"的分析都必须先条件化。**

**③ 分类准确率是错误判据**

```
跟随偏置策略: 0.4948
总是猜"不出现": 0.8182
```

在 18% 基础率下，"猜不出现"天然 82% 正确。**必须用命中率（top-6 交集数），不能用准确率。**

### 7.3 还剩什么理论方向

诚实列出，按剩余可能性排序：

| 方向 | 理论依据 | 卡在哪 |
|---|---|---|
| 三阶/更高阶交互 | 若存在复杂结构 | 条件化后已证二阶无结构，高阶更弱 |
| 跨期结构（期 t 与 t-k 的组合相关性） | 若摇奖机有周期 | V30 自相关全在 2se 内 |
| 开奖顺序的**排列**结构 | 物理摇奖的球位偏差 | V30 测过位置 χ²，多重比较后 p=0.4560 |
| 异常期次（设备更换、规则变更） | 制度变化可能改变分布 | **未测，这是唯一剩下的** |

**只有最后一条没做过。** 但它是"分段"问题，本质上是把自己切成更小的样本——每个子段样本量锐减，检验力更低。
