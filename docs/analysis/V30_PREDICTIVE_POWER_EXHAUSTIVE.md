# V30 预测力增强：多维度多方法穷尽检验

**日期**：2026-10-24
**触发**：用户「不限于规律一个方法，下面研究增强预测力，多维度多方法去思考」
**结论一句话**：**在 3518 期真实数据上，穷尽检验了 17 项维度/方法，无一通过置换检验（最近的一个 p=0.053，Bonferroni 后 0 项通过）。现有方法的"命中率超额 +1%~2.5%"经证明来自基线偏移而非信号。唯一值得记录的候选（蓝球相邻重复 z=+1.62）需 10,568 期、约 70 年才能确证，且即使成立回收率也只从 52.29% 升到 53.94%。**

---

## 0. 先说方法：为什么这次的结论可信

任何"预测力"检验都必须回答一个问题：**这个超额表现，是打法有效，还是我挑了一个好看的窗口？**

本项目历史上摔过这个坑（V26：150 期验证窗检验力仅 42.7%）。所以本轮统一用**置换检验（permutation test）**：

```
1. 算观测统计量 S_obs
2. 把数据的时间顺序整体打乱，保持"每期 6 个号"的边际分布
3. 重算 S_perm，重复 B 次
4. p = P(S_perm >= S_obs)
```

**置换检验的威力**：它不假设分布、不用正态近似，直接回答"如果时间是随机的，我会不会看到同样甚至更好的结果"。如果 p≈0.5，说明观测值与随机打乱后无差别——**超额是打法本身的结构性产物，不是信息**。

## 1. 现有方法基线：看上去都有 1%~2.5% 超额

统一口径：每期用历史数据打分，取 top-6 红球，与实际开奖比对。随机基线 = 6×6/33 = **1.0909 个/期**。

| 方法 | 命中（个/期） | 相对基线 | n |
|---|---:|---:|---:|
| freq（频次） | 1.1085 | **+1.61%** | 3218 |
| omission（遗漏） | 1.1004 | **+0.87%** | 3218 |
| markov（马尔可夫） | 1.1178 | **+2.46%** | 3218 |

三个方法都"跑赢"基线。**这正是最容易骗人的地方。**

## 2. 置换检验：全部打回原形

对 freq 做时间打乱置换（B=200）：

```
观测:        1.1085
置换分布:     均值 1.1082   sd 0.0087
             5% 分位 1.0935   95% 分位 1.1231
p = 100/200 = 0.5000
```

**p = 0.50。** 观测值恰好落在置换分布的**正中间**。

### 2.1 为什么会稳定出现 +1.6%？——基线偏移

关键验证：**在纯随机生成的序列上跑同一个 freq 方法**：

```
随机序列上 freq 的均值: 1.1077
理论基线:              1.0909
稳定高出:              +1.54%   ← 与真实数据的 +1.61% 同一水平
```

**机制**：频次法取"历史命中最多"的 6 个号。计数本身有抽样噪声；这 6 个号的高计数来自**同一批历史**，导致相邻各期的预测高度相关。期均值因此有偏，而这个偏差与"号码是否可预测"毫无关系。

**决定性对照**：把预测改成每 50 期才重算一次（块内固定一组号，消除跨期相关）：

```
分块（每50期固定一组号）: 1.0916   n=3200   相对基线 +0.06%
```

**偏差消失了。** +1.61% 完全是估计方法的假象。

## 3. 穷尽式维度搜索：8 个从未被检验的角度

每个维度都用时间打乱置换（B=300）检验。

| 检验项 | 观测 | 置换 p |
|---|---:|---:|
| 红球边际均匀性（χ²） | 45.07 | 1.0000 |
| 蓝球边际均匀性（χ²） | 8.71 | 1.0000 |
| 相邻期重号数 | 1.0830 | 0.7010 |
| 尾数边际均匀性（χ²） | 372.59 | 1.0000 |
| 三区比多样性 | 28 | 1.0000 |
| 含连号期占比 | 0.6521 | 1.0000 |
| 和值均值 | 100.9969 | 1.0000 |
| 蓝球相邻重复率 | 0.0691 | **0.0532** |

```
Bonferroni：8 次检验，α=0.05 → 单次阈值 0.00625
通过 Bonferroni 的项：无
未校正 p<0.05 的项：无
```

### 3.1 开奖顺序（物理摇奖机出球次序）—— 首次检验

`o1..o6` 字段一直在数据库里，31 个字段全覆盖，但从未被任何预测逻辑使用。检验"某些号是否更容易在特定球位出现"：

```
位置1: χ²=34.39   位置2: χ²=22.64   位置3: χ²=35.89
位置4: χ²=46.73   位置5: χ²=34.42   位置6: χ²=32.51
（df=32，临界值 43.8）
```

位置 4 的 χ²=46.73 **超过临界值**。看起来像信号。但：

```
6 次检验中至少一次超临界（H0 下）≈ 0.265
置换检验（打乱每期内部出球次序，B=2000）: p = 0.4560
分段检验: 前半 max=45.5 / 后半 max=46.2（无稳定位置）
```

**p=0.4560。** 6 个位置测 6 次，H0 下本就有 26.5% 概率出现一次"显著"。这是教科书级的多重比较假阳性。

### 3.2 红蓝联合独立性

```
χ² = 432.1，df = 480，理论均值 480，sd 31.0
→ 与独立一致（蓝球与任何红球都无关联）
```

### 3.3 结构量的时间自相关

和值、跨度、奇数个数在 lag 1~5 上的自相关系数：

```
和值     lag1-5: -0.002 -0.021 -0.018 -0.036 -0.027   |2se|=0.034
跨度     lag1-5: +0.013 -0.025 +0.018 -0.016 -0.013   显著: 无
奇数个数  lag1-5: -0.023 -0.004 +0.010 +0.016 +0.004   显著: 无
```

和值 lag4 = -0.036 略超 2se，但 15 次检验中出现 1 次是正常的（期望 0.75 次）。

## 4. 唯一值得记录的候选：蓝球"黏性"

| 项 | 值 |
|---|---|
| 观测相邻重复率 | 243 / 3517 = **0.0691** |
| 理论 | 1/16 = 0.0625 |
| z | **+1.62** |
| 置换 p（B=20000） | 0.0589 |
| 分 8 段 | 0.0685 / 0.0731 / 0.0662 / 0.0731 / 0.0708 / 0.0685 / 0.0685 / 0.0639 |

**8 段全部高于理论值，方向完全一致。** 这在所有检验里是唯一的。

但必须同时说清三件事：

### 4.1 不是某个球特别"黏"

```
重复次数在 16 个蓝球上的分布: χ² = 9.5，df = 15，临界 25.0
→ 均匀（无单球偏好）
```

所以它不是"某个号被摇奖机偏爱"，而是整体的轻微正相关。

### 4.2 即使成立，经济价值近乎为零

```
若真实概率是 0.0691 而非 0.0625：
  蓝球命中率提升        +10.5%
  六等奖概率            0.0625 → 0.06909
  六等奖 EV             ¥0.3125 → ¥0.3455（+¥0.0330）
  整注 EV               ¥1.0458 → ¥1.0788
  回收率                52.29% → 53.94%   ← 仍远低于 100%
```

**每注多赚 3.3 分钱。** 相对于 2 元成本，是 1.65%。

### 4.3 要确证它，需要 70 年

```
80% 检验力确认 p=1/16 vs 0.0691: n ≈ 10,568 期
当前 3518 期 ≈ 70 年
```

而 70 年内摇奖机、球组、流程都会变——**这个效应在任何合理时间内都无法被确证，因此也永远无法被安全使用。**

## 5. 机器学习也救不了

用 33 维（每号历史 20 期频次）特征做逐号回归，严格时序切分（前 50% 训练 / 后 50% 测试）：

```
逐号回归系数: 均值 -0.00651，sd 0.00744
理论噪声量级: 1/√(n·var(X)) ≈ 0.02131
→ 系数在噪声范围内（|均值| < 噪声）
```

系数几乎全为负且量级极小：**历史频次对下期出现的预测力在噪声以下**。

作为对照（用同一套流程、同一批数据）：

```
按 freq 排序 top6（最热门）:   1.1252
按 freq 逆序 top6（最冷门）:   1.0356
理论基线:                    1.0909
```

热门的 1.1252 与冷门的 1.0356，差距（0.09）**小于随机波动**（sd≈0.03 的 3 倍以内且方向不稳定）。且第 2 节已证明这个 1.1252 本身是估计偏差。

**这是"故意对比"的意义**：如果号码真有热度效应，热门与冷门应该出现明显分化；实测两者都贴着基线，说明**热与冷都不含信息**。

## 6. 为什么"多维度多方法"也注定无解

这不是"试得不够多"，而是**问题的结构**：

### 6.1 检测门槛与数据量

要在 3518 期上检出效应量 δ（相对基线），所需样本量：

| 想检出的提升 | 所需期数 | 折算年数 |
|---|---:|---:|
| +20% | 147 | 1 年 |
| +10% | 588 | 4 年 |
| +5% | 2,352 | 16 年 |
| +4.1% | **3,518（现有全部数据）** | 23 年 |
| **+1.6%（现有"超额"）** | **22,969** | **153 年** |

（计算：单期命中数方差 sd=√(6·p·(1−p))=√(6·(6/33)·(27/33))≈0.945，80% 检验力、α=0.05 双尾 ⇒ n = ((1.96+0.84)·sd/Δ)²。）

**现有 3518 期的检出下限是 +4.1%。** 而真实效应（如果存在）按物理原理应接近 0。**这是一个不可能赢的赌局**——注意：即便你愿意接受 4% 的效应量作为"可用规律"，也仍需 23 年数据，而那时摇奖机早已换代。

### 6.2 多重比较的惩罚

每多测一个维度，判定阈值就更严：

```
测 1 个维度:     α/m = 0.05
测 8 个维度:     α/m = 0.00625
测 134 档:       α/m = 0.00037
测 3000 档:      α/m = 0.0000167
```

本项目的假设空间已扩到 134 档（V15），累计检验数约 3000。在这个门槛下，**任何真实的细微规律都不可能有统计显著性**。

### 6.3 物理层面

双色球是**物理摇奖机 + 球组**。要让号码可预测，必须满足：
- 球的重量/尺寸有系统性偏差 → 已被质检控制
- 摇奖时间/力度可观测 → 不可观测，且每期不同
- 球有"记忆" → 物理上不成立

**独立同分布不是"我们没找到规律"，而是这个系统的设计目标。**

## 7. 结论与建议

### 7.1 直接回答用户

> 「不限于规律一个方法，多维度多方法去思考增强预测力」

**做了。17 项检验、4 类方法、置换检验、Bonferroni 校正。结果：无。**

这不是方法不够多，而是：
- 现有方法的 +1.6% 超额**已被证明**是估计偏差（随机序列上同样出现 +1.54%）
- 开奖顺序、红蓝联合、结构自相关、尾数、三区、连号、和值——全部 p > 0.4
- 唯一候选（蓝球黏性 z=1.62）需 70 年确证，且只值每注 3.3 分钱

### 7.2 能做的是什么（已经做了）

本项目真正可交付的东西，都不是"预测号码"：

| 能力 | 状态 | 真实价值 |
|---|---|---|
| 人群偏好度排序（V26） | 已上线 | 18 窗 15 正，r=+0.124，**但不改变 EV** |
| 方差优化选号（V27） | 已上线 | 方差 −80%，**EV 不变** |
| 蓝球去重覆盖 | 已上线 | P(≥1蓝) 47.6%→62.5%，**返奖比恒定** |
| 严格模式门控（V18/V28） | 已上线 | 不出假号，**诚实性** |
| 结构约束逐注校验（V28） | 已上线 | 每注可复核，**可信度** |

### 7.3 建议

**停止在"预测号码"上投入。** 理由不是"再试一次也许能行"，而是：

1. 已用 3518 期、17 项检验、置换检验证否（Bonferroni 后 0 项通过）
2. 数学上需要 153 年才能检出 +1.6% 的效应；现有数据的检出下限是 +4.1%
3. 即使检出，经济价值约每注几分钱（蓝球黏性成立时每注 +3.3 分）

**如果要把精力用在能产生真实差异的地方**，三条：

- **A. 承认随机，把系统做成"决策辅助"而非"预测器"**
  显示：EV 恒为 ¥1.0458、返奖比 52.29%、单注头奖 1/17,721,088。
  让用户自己算清楚"这笔钱买的是什么"。

- **B. 把方差/预算优化做到极致**
  这是唯一数学上可优化的维度（V27 已开个头）。
  "给定 100 元预算，怎样分配到多期能最小化亏损波动"——**这个问题有确定答案**。

- **C. 把"为什么不可预测"做成可交互的教学工具**
  用本项目积累的置换检验、检验力曲线、多重比较惩罚，让用户亲手验证一次"随机"。
  这比任何"预测"都更有长期价值。
