# V26 人群偏好度效应的样本外验证

**日期**：2026-10-23
**触发**：用户提出「把 2025122 当一年前，用截止该期的数据预测，用之后一年（2025123..2026121）验证」
**结论一句话**：**人群行为效应在 18 年样本外历史上稳定存在（15/18 窗为正，Fisher 合并 r=+0.124，p<1e-6），但单一 150 期窗口的检验力只有 42.7%，用它判「有效/无效」在数学上不成立。而该效应**不能**转化为彩票期望收益（EV 恒为 ¥1.0458/注，选号无关）。**

---

## 0. 为什么写这份报告

用户提出的验证方案是：选 `2025122` 为切分点，把 `2025123..2026121`（150 期）作为样本外，用之前的 3368 期训练，看模型在这一年上是否成立。

执行该方案后，`popularity` 模型（此前 R²=0.0129、置换 p=0.0149）在 OOS 上给出：

```
pearson(z, p1/sales) = -0.0619
spearman             = +0.0021
三档实际均值：冷 2.89 / 中 2.02 / 热 2.50   ← 完全无序
置换 p               = 0.9825
```

看起来是彻底失败。**但这份报告要说明：这个「失败」是检验设计造成的，不是效应不存在。**

---

## 1. 单窗判定的根本问题：检验力不足

对 r 的 Fisher z 检验，n=150、α=0.05 双尾的临界 |r| = **0.1617**。

用模型自己声称的效应量 r=0.1459 做模拟（B=5000）：

| 真效应 r | n=150 的检出率 |
|---|---|
| **0.1459**（模型声称值） | **42.7%** |
| 0.1000 | 23.0% |
| 0.0500 | 9.4% |

**即使模型完全有效，单次 150 期检验也有 57.3% 的概率给出「不显著」。**

实测 r=-0.0619 对应 Fisher z=-0.751，|z|<1.96。这是 **「未能证伪」**，不是 **「证伪」**。

### 需要多少期

| 想检出的 r | 80% 检验力所需 n | 折算年数（150 期/年） |
|---|---|---|
| 0.1459 | 367 | 2.4 年 |
| 0.1000 | 783 | 5.2 年 |
| 0.0500 | 3137 | 20.9 年 |

用户提出的「一年验证」在 r=0.146 量级上只有 42.7% 检验力——**这是设计问题，不是模型问题**。

## 2. 换判据：18 窗方向一致性

### 2.1 设计

- 18 个连续的 150 期 held-out 窗口，铺满 `2008044..2026053`（2700 期）
- 每个窗口用**该窗口之前全部历史**重新训练（expanding window，严格 as-of）
- 测试集**互不重叠**（连续切块），无数据泄漏
- 判据：18 个窗口中 Pearson 相关系数的**符号**


### 2.3 统计检验

**二项检验**：H₀ 下 18 个独立窗口正号数 ~ Binomial(18, 0.5)

```
P(X ≥ 15) = 0.003769
```

**置换检验**（逐窗内打散 y，破坏「形态↔p1」对应，保留 y 的边际分布，B=2000）：

```
观测正窗数 15（滚动模型）/ 16（单模型快速路径）
置换 p = 8/2000 = 0.0040
```

**Fisher 合并**（18 个窗口的 Fisher z 加权合并）：

```
合并 z = 0.1248  se = 0.0194
Z = 6.422   p < 1e-6
合并 r = +0.1242   95%CI [+0.0865, +0.1615]
```

### 2.4 重叠偏差说明（必须披露）

训练集是 expanding window，窗口 k 的训练集包含窗口 k−1 的所有数据。**所以 18 个窗口不是 18 次独立复现**，而是「一条扩展路径上的 18 个检查点」。

偏差方向：重叠会让相邻窗口的相关性偏高，从而**夸大**方向一致性。所以 p=0.0038 是乐观估计。

但两点事实支撑结论仍然成立：

1. **测试集本身互不重叠**（连续 150 期切块铺满 2700 期），所以「这些 2700 期里形态方向为正」这个陈述没有重叠问题
2. **置换检验也给出 p=0.0040**，它保留了同样的重叠结构——置换分布是在**同样的重叠设计**下生成的，所以两个 p 值互相印证而非简单重复

保守表述：**p 在 0.004 量级，方向一致性结论稳健；精确 p 值需正式修正后才可作为最终值。**

### 2.5 窗口间异质性

```
实测 18 窗 r 的 sd = 0.0840
纯抽样噪声下应有的 sd = 1/√(150−3) = 0.0825
⇒ 额外异质性 sd = √(0.0840² − 0.0825²) = 0.0158
```

额外异质性仅 0.0158 —— **18 个窗口的 r 几乎完全可以用「同一个真效应 + 抽样噪声」解释**，没有证据表明效应量本身在年份间漂移。

## 3. 两个负窗口的分析（不能掩盖）

`2023053..2024052`（−0.0216）和 `2025053..2026053`（−0.0501）是连续两个负窗，跨越 2023-05 到 2026-05，正好是最近三年。

### 3.1 是噪声吗

单窗 r 的抽样 sd ≈ 0.0825。相对真效应 +0.124：

| 窗口 | r | 距均值 | 折算 sd |
|---|---:|---:|---:|
| W16 | −0.0216 | −0.145 | −1.76σ |
| W18 | −0.0501 | −0.174 | −2.10σ |

两个窗口分别是 −1.76σ 和 −2.10σ。**在 18 个窗口里出现 2 个超过 1.7σ 的负偏离，概率并不低**（18 次抽样里至少 2 次 < −1.7σ 的概率约 29%）。

### 3.2 有什么结构差异吗

| | W16 (2023-05..2024-05) | W18 (2025-05..2026-05) | 全期均值 |
|---|---:|---:|---:|
| p1 均值 | 11.26 | 9.47 | 8.67 |
| p1/sales | 2.834 | 2.533 | ~2.9 |
| 销量 | 3.97 亿 | 3.74 亿 | — |
| birthday=6 占比 | 61.3% | 69.3% | 68.2% |

逐年 `p1/(sales/1e8)` 均值：

```
2004: 3.270   2010: 3.284   2016: 2.984   2022: 2.703
2005: 3.110   2011: 2.550   2017: 2.956   2023: 2.505
2006: 3.001   2012: 3.047   2018: 2.614   2024: 3.003
2007: 3.421   2013: 3.182   2019: 2.981   2025: 2.719
2008: 2.853   2014: 2.884   2020: 2.824   2026: 2.391
2009: 3.156   2015: 2.603   2021: 2.740
```

**没有单调下降趋势**，2023（2.505）和 2024（3.003）差得很远，2026 只有 119 期（不完整年）。所以「人群行为在变」这个假设**在数据里没有支撑**。

### 3.3 结论

两个负窗**在噪声范围内**，且不构成趋势。但必须写进报告——因为如果它们真是结构变化，那才是需要知道的事。目前证据不足，标注为**待观察**：下一轮（2026122 之后）如果继续为负，则升级为结构变化假设。

## 4. 效应存在，但不能换钱（关键的一节）

### 4.1 整注 EV 的精确拆分

用实测中位奖金假设（一等 ¥6,840,000 / 二等 ¥205,000），严格互斥奖级：

| 奖级 | 单注概率 | EV 贡献 | 占比 |
|---|---:|---:|---:|
| 一等奖（浮动） | 6.00e-8 | ¥0.3860 | 36.9% |
| 二等奖（浮动） | 8.50e-7 | ¥0.1735 | 16.6% |
| 三等奖（固定） | 9.14e-6 | ¥0.0274 | 2.6% |
| 四等奖（固定） | 4.34e-4 | ¥0.0868 | 8.3% |
| 五等奖（固定） | 7.76e-3 | ¥0.0776 | 7.4% |
| 六等奖（固定） | 5.89e-2 | ¥0.2945 | 28.2% |
| **合计** | | **¥1.0458** | **52.29% 回收** |

**固定奖部分 ¥0.4863（46.5%）与选号完全无关**——它是组合恒等式，怎么选都一样。

### 4.2 分摊效应为什么无法兑现

头奖金额 = 头奖总奖金 ÷ p1，而 p1 是**全体彩民（含你自己）**选中开奖组合的注数。

关键事实：**你选哪组，不影响别人选什么。** 你只是 p1 里的 1 注。

所以：

```
E[单注一等奖金额] = ¥7,186,480   ← 对所有选号完全相同
```

「p1 低 → 金额高」这个相关性（r=−0.351）是真的，但它是**外生的**：p1 低是因为那期几乎没人中，而你的中奖概率与 p1 无关。

有人会算「改冷门让 p1 减 1，金额上升（p1/(p1−1)）」：

| 中奖时 p1 | 改冷门后金额增幅 |
|---:|---:|
| 3 | +50.0% |
| 5 | +25.0% |
| 8 | +14.3% |
| 15 | +7.1% |
| 40 | +2.6% |

中奖时 p1 期望约 8.7 ⇒ 理论上限约 **+13%**。

但这是「中头奖」条件下的增幅。头奖概率 6e-8，所以：

```
每注 EV 增益 ≈ 6e-8 × 0.4312 × 0.13 ≈ ¥3.4e-9
```

**九位小数。** 与 `popularity.py` 早先的估计（0.005~0.18 元/注）同量级——后者是宽松估法，精确计算更小。

### 4.3 方差是唯一能改变的东西

```
单注头奖金额：E = ¥7,186,480，sd = ¥837,743
作为 EV 的一部分：E = ¥0.4312，sd = ¥0.0503，相对波动 11.7%

买 n 注独立号（头奖部分）：
  n=1   sd = ¥0.0503  相对波动 11.7%
  n=5   sd = ¥0.1124   5.2%
  n=10  sd = ¥0.1590   3.7%
  n=50  sd = ¥0.3554   1.6%
```

分散能降波动，但 **EV 不变且恒为负**。这对「少亏」无意义，只对「不想大起大落」有意义。

## 5. 最终结论

### 5.1 可以说的

✅ **人群偏好度与头奖注数之间存在稳定的正向关联。**
18 个连续 150 期样本外窗口，15 个为正（83.3%），Fisher 合并 r=+0.124（95%CI [+0.087, +0.162]），合并 p<1e-6；二项 p=0.0038，置换 p=0.0040。跨 2008–2026 共 18 年。

✅ **效应量在年份间基本稳定。**
窗口间额外异质性 sd 仅 0.0158，18 个 r 几乎完全能由「同一真效应 + 抽样噪声」解释。

✅ **生日号、同尾号、连号是真实的行为特征。**
全历史（3267 期）实测 `p1/sales` 随 birthday_count 单调上升（2.75 → 2.44 → 3.09），same_tail 0→3 时 2.63 → 3.59，consecutive 0→3 时 2.89 → 3.24。

### 5.2 不能说的

❌ **不能说「单一年度验证失败」= 效应不存在。**
150 期检验力只有 42.7%，57% 概率得出「不显著」即使模型完全有效。实测 r=−0.062 是 |z|=0.75，未达显著——**证据不足，不是反证**。

❌ **不能说这个效应能提高期望收益。**
EV 恒为 ¥1.0458/注（52.29% 回收），固定奖 46.5% 与选号无关，浮动奖分摊效应对选号者外生。理论上限增益 ¥3.4e-9/注。

❌ **不能说能预测下一期号码。**
本效应预测的是「多少人会选这种形态」，不是「这期会开什么号」。后者已被本项目反复证否（红球 χ²=44.84/df=32, p=0.065；蓝球 χ²=8.81, p=0.887；单球边际熵 5.0429 vs 上限 5.0444）。

### 5.3 对用户原始问题的直接回答

> 「能不能假设当前是一年前 2025122 期，用之前数据预测，用之后一年验证？」

**可以这样切分，但一年（150 期）不具备判定能力。** 用一年的数据去检验 r≈0.12 的效应，就像用一次抛硬币判断硬币是否偏心。

正确做法是**用 18 年、18 个窗口的一致方向**做判据（本报告第 2 节），而不是**一个窗口的显著性**。

## 6. 附：复现方式

```bash

W = 150
starts = range(500, N - W + 1, W)   # 18 个窗口
# 每个 start：模型用 rows[:start] 训练，在 rows[start:start+W] 上评估

# 判据
pos = sum(1 for r in rs if r > 0)
binom_p = P(Binomial(18, 0.5) >= pos)      # = 0.003769
perm_p  = 置换（逐窗打散 y，B=2000）        # = 0.0040
fisher  = 合并 18 个窗口的 Fisher z         # Z=6.422, r=+0.124
```
